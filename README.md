# Book Manager - Sprint 1

## Objetivo

Aplicar los conocimientos adquiridos en programacion orientada a objetos y almacenamiento de datos en archivos para su persistencia.

## Introduccion y contexto

Una libreria con venta al publico necesita modernizar su sistema de gestion de inventario de libros. Debido a la fluctuacion en los costos de importacion de material bibliografico, el sistema debe gestionar precios en diferentes monedas y seguir de cerca la cotizacion del dolar. Se desarrolla una aplicacion de consola (CLI) en Python que permite gestionar el inventario, cotizar los libros segun el valor del dolar y administrar el stock.
